Features

Everything in one workbench

Chat, project and tools side by side. Switch between one, two and three columns, or fold the sidebar with ⌘B and the tools with ⌘J.

Bring your own key

Use Anthropic or OpenRouter. Keys stay in your macOS Keychain (on Windows, in a per-user file outside your projects), never in a project file.

Diff and revert

See what each turn changed, file by file. Undo one file, or the whole turn with Rewind.

Git built in

Stage, commit, push and create branches without leaving the app. Pushes are never forced.

Terminal tab

Run your own commands next to the chat, in your own login shell.

Images and @files

Paste or drop screenshots. Type @ to point the agent at any file in the project.

Your instructions

Extend or replace the system prompt. Add slash commands, skills and MCP servers.

Native notifications

A native notification when a task finishes or needs your approval, while you work elsewhere.

Chats per project

Resume, export to Markdown or delete the saved chats of every workspace.

Safety

Safe by default

The agent asks before it acts, and some things it never does without an explicit yes.

Permission modes

Default asks before edits and commands. Accept-edits allows file changes. Plan mode only reads. Bypass is opt-in.

Catastrophic commands

rm -rf ~, dd to a disk and friends always ask, in every mode, and are never remembered.

Untrusted projects

A project’s allow rules, hooks and MCP servers do nothing until you trust that workspace.

Install

Up and running in a minute

Builds for macOS (Apple Silicon and Intel) and Windows (64-bit).

Builds are not signed or notarized yet. Only install builds from the official Releases page. The repository is currently private, so the Releases page and the source below need access to it (ask the maintainer); both become public once the repository is.

  1. Download the build for your system from the project’s Releases page: the .dmg on a Mac (arm64 for M1 and later, x64 for Intel) or the .exe installer on Windows.
  2. macOS: open the .dmg and drag mini-coding-agent into Applications. macOS blocks the first launch of unsigned apps, so run this once: 
    xattr -dr com.apple.quarantine "/Applications/mini-coding-agent.app"
  3. Windows: run the installer. SmartScreen warns about unsigned apps: choose More info, then Run anyway. Install Git for Windows for the best experience: MCA then runs commands in Git Bash and applies its full command safety rules. Without it, MCA falls back to PowerShell and asks before every command.
  4. Open the app, pick a provider, paste your API key and open a workspace.
CLI

Also in your terminal

The same agent, scriptable. mca works interactively and in pipelines.

mca -p "explain src/main" --permission-mode plan
git diff | mca -p "review this diff"
mca --continue

Install from source (Node 20.12 or newer, repository access required):

git clone https://github.com/yurtemre7/mini-coding-agent
cd mini-coding-agent && npm install && npm run build && npm link
mca --help
