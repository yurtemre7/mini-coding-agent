A coding agent you stay in control of

MCA runs on your Mac with your own API key. It reads, edits and tests your code, and shows every change before you keep it.

Install for macOSUse the CLI
Add a /resume command and a test for it
Edit src/core/commands.ts+18 -2
Bash npm testpassed

Done. The command lists saved chats and resumes one. All tests pass.

Everything in one workbench

Chat on the left, your project in the middle, tools on the right. Fold any column away.

Bring your own key

Use Anthropic or OpenRouter. Keys stay in your macOS Keychain, never in a project file.

Diff and revert

See what each turn changed, file by file, and undo a file or a whole turn with Rewind.

Git built in

Stage, commit, push and create branches without leaving the app. Pushes are never forced.

Terminal tab

Run your own commands next to the chat, in your own shell.

Images and @files

Paste or drop screenshots, and type @ to point the agent at a file.

Your instructions

Add to or replace the system prompt, define slash commands and skills, connect MCP servers.

Native notifications

Get a macOS notification when a task finishes or needs your approval.

Chats per project

Resume, export to Markdown or delete saved chats for each workspace.

Safe by default

The agent asks before it acts, and some things it never does without an explicit yes.

Permission modes

Default asks for edits and commands. Accept-edits allows file changes. Plan mode only reads. Bypass is opt-in.

Catastrophic commands

Commands like rm -rf ~ or dd to a disk always ask, in every mode, and are never remembered.

Untrusted projects

A project's allow rules, hooks and MCP servers do nothing until you trust that workspace.

Install on macOS

Apple Silicon and Intel builds are available.

  1. Download the .dmg for your Mac from the project's Releases page (arm64 for M1 and later, x64 for Intel).
  2. Open it and drag mini-coding-agent into Applications.
  3. The app is not signed or notarized yet, so macOS blocks the first launch. Run this once: 
    xattr -dr com.apple.quarantine "/Applications/mini-coding-agent.app"
  4. Open the app, pick a provider, paste your API key and open a workspace.

Unsigned builds are a temporary limitation. Only install builds you got from the official Releases page.

Also a CLI

The same agent, scriptable. mca works in your terminal and in pipelines.

mca -p "explain src/main" --permission-mode plan
git diff | mca -p "review this diff"
mca --continue
